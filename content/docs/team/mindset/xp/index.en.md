# XP Values
XP is based on five values.

- Communication

  Everyone on the team works together at every stage of the project.

- Simplicity

  Developers strive to save time and effort by writing simple code that brings value to the product.

- Feedback

  Team members deliver software frequently, get feedback on it, and improve the product in response to new requirements.

- Courage

  Without making excuses, evaluate your own results objectively and respond to change.

- Respect

  Everyone involved in the project contributes toward a common goal.
