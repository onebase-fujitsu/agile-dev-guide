# Script Creation

## Overview

In script creation, you create a talk script that organizes the flow of the research session and the items to check.

Include the following:
- Target users
- The purpose of this research and the hypotheses to validate
  - Generative
  - Evaluative
  - Usability
- Things to prepare
- The script itself
  - What the interviewer says
  - Tasks to request / hypotheses to check
  - Items to check

## Key Points of Script Creation

- Always do a rehearsal beforehand
  - Have someone play the interviewee
- Don't be particular about the format; adjust it so it is easy for the interviewer to talk
