# Summary

Extreme Programming (XP) is an agile development process built from a simple and concrete set of practices.
This development process is used by many teams and has achieved substantial results.

XP is a highly versatile software development method, and it should be possible to adopt it in many development projects.
And it is essential for each development team to add and change practices through retros, shaping a set of practices that better suits the team.
