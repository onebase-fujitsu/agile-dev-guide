# Getting Started with Software Testing

So far we have learned about agile, Scrum, and XP.
Since each of those was about mindsets and frameworks,
many of you are probably wondering, "So how exactly do we actually develop software?"

Don't worry: the main part of this document starts here!

In this chapter we will talk about software testing,
but unlike the previous chapters, it is designed as a hands-on chapter where you learn by doing.
Please get your favorite IDE or text editor ready as you read this chapter.

If you are not comfortable with programming, don't worry: we start with simple programs.

Let's get started.
